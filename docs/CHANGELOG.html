Changelog

Keep a Changelog format, semantic versioning. Markdown source: docs/CHANGELOG.md.

1.2.0 — 2026-10-16

  • added Live decoder switching — the player's stream panel switches between hardware and FFmpeg decoding while the video keeps playing, through NextLib's DecoderManager attached to the one ExoPlayer; the UI asks the service over a custom Media3 session command and the service applies it on the player's thread and remembers it
  • added Audio track picker — the control row lists every audio track of the current file (codec, channels, language) and switches between them through TrackSelectionParameters; TrackOptions builds the list so the indices handed back are the ones the player reported
  • added Subtitle auto-discovery — a .srt / .vtt / .ass file with the video's own name (or a language tag such as Movie.th.srt) loads by itself: exact name first, then the device language, then the rest, and files of other videos never match
  • added A new SUBTITLE log tag that records every subtitle search, including the ones that find nothing
  • added 17 more JVM tests (71 in total): subtitle name rules, the decoder preference table and audio track options built from real Media3 Tracks objects
  • changed Hardware only now means hardware MediaCodec decoders only; the FFmpeg renderers stay built in every mode, because the renderer set is fixed when the player is created — that is what makes switching to FFmpeg mid-video possible
  • changed Subtitle auto-discovery reads MediaStore, so on Android 13 and newer it only sees subtitle files this app owns; the subtitle button still takes any file you pick

1.1.0 — 2026-10-16

  • added Wi-Fi transfer (`Transfer` tab) — send files from one phone to another on the same network: no cable, no cloud, no account
  • added Receive mode runs a small HTTP server, shows the address and a four digit code, and advertises over mDNS so the other phone finds it without typing
  • added Send mode lists discovered receivers or takes a typed address (192.168.1.20, 192.168.1.20:45871, http://…), with a Check button before you pick files
  • added Several files per transfer with progress, cancel and per-file outcomes; a cancelled or interrupted transfer leaves no partial file behind, and the receiver stays usable
  • added Received videos are published to Movies/VDO Player through MediaStore IS_PENDING and appear in the library at once; other files go to Download/VDO Player
  • added Files whose size a provider does not report are streamed with a chunked request body — the sender never holds the whole file in memory
  • added New TRANSFER log tag records every incoming and outgoing file with its size and the peer address
  • added ACCESS_LOCAL_NETWORK and its runtime prompt for Android 17, which blocks local network traffic — mDNS included — for apps targeting SDK 37
  • added Wi-Fi Direct for phones with no router between them: the receiving phone opens a group, the sender joins it, and the group owner appears in the normal receiver list. Asks for NEARBY_WIFI_DEVICES (13+) or ACCESS_FINE_LOCATION (≤12) when first used
  • added Repeat in the player's control row: off → the whole queue → this video, announced on screen and remembered for the next session
  • added Seek preview: dragging the progress bar or scrubbing with a swipe decodes a frame of the target position into the heads-up display, cached per two-second bucket and switchable in Settings
  • added 54 JVM unit tests over the wire protocol, the file-name sanitiser, the chunked path, cancellation, the repeat cycle, the seek-preview policy, the Wi-Fi Direct address rules and translation completeness; CI runs them before building a release
  • added GitHub Actions release workflow (.github/workflows/release.yml): a v* tag runs the tests, builds the four APKs, signs them from repository secrets and opens a draft release with the SHA-256 checksums in the run summary
  • changed The manifest now declares INTERNET and ACCESS_NETWORK_STATE for the transfer sockets. Nothing is uploaded to the internet; files only move between two phones on your own network
  • fixed File names keep Thai vowel marks and ordinary punctuation — only what a file system cannot take becomes _
  • fixed Long file names are shortened without losing the extension, so a long video still lands in Movies
  • fixed Cancelling an upload says “Cancelled” instead of an internal I/O error, and a sender walking away is no longer logged as an app failure
  • fixed The transfer screen resolves its probe wording at composition time, so a language change while it is open cannot leave a stale message behind

1.0.1 — 2026-10-15

  • added Thai (th) translation of the whole interface — heads-up display, track info panel and export snackbars included
  • added locales_config.xml and android:localeConfig, so Android 13+ lists English and Thai under App languages
  • added Every user-visible string moved out of the composables into resources; enum display names resolve through ui/Labels.kt
  • added The playback notification channel is named by the app, so it follows the selected language
  • added The three count strings became <plurals>, so English reads “1 video” and “1 log line”

1.0.0 — 2026-10-15

First public release. Everything below is new.

Library

  • added MediaStore scan with a ContentObserver, so the list updates while the app is open
  • added Thumbnails decoded from the video frames themselves (Coil 3 + coil-video)
  • added Search by title or folder, folder filter chips, seven sort orders
  • added Grid layout with 1–4 columns and a single-column list layout
  • added Long-press details: folder, resolution, duration, size, MIME type, relative path, URI

Playback

  • added ExoPlayer hosted in a MediaSessionService, driven through a MediaController
  • added FFmpeg software decoders via nextlib-media3ext, three priority modes
  • added Playlists from the filtered library view with previous/next
  • added Per-video resume positions, throttled to one write every 5 seconds
  • added Background audio with a media notification that returns to the player
  • added 0.25×–3× speed, plus a 3× long-press boost
  • added Aspect modes, control lock, rotation, picture-in-picture with the real aspect ratio
  • added Side-loading of .srt, .vtt and .ass subtitles, and a subtitle toggle
  • added Gesture layer: brightness, volume, scrub, double-tap seek, all with on-screen feedback

Diagnostics

  • added LogBus — 2000-entry ring buffer, versioned snapshots, logcat mirroring, 8 tags, 6 levels
  • added LogFileWriter — asynchronous rotating files, 2 MB × 10
  • added CrashGuard — uncaught exceptions logged with a device summary and flushed before exit
  • added Diagnostics — device, OS, ABI, display, memory, storage, player state, active tracks, MediaCodec inventory
  • added LogShare — .txt/.zip exports, share sheet delivery, save to Downloads
  • added Logs screen: level/tag/text filters, freeze the live tail, copy, clear, share, save

App

  • added Material 3 with dynamic colour, light/dark/system themes
  • added Settings for appearance, playback and diagnostics
  • added Recent tab with per-entry progress, remove and clear-all
  • added Handles ACTION_VIEW and ACTION_SEND for video/* and audio/*
  • added Adaptive launcher icon with a monochrome variant for themed icons

Distribution

  • added Per-ABI release APKs plus a universal APK, signed with the project key
  • added This GitHub Pages site, resolving the newest release through the GitHub API
  • added Markdown and HTML documentation

Known limitations

  • limit No device-level smoke test ran: playback correctness is asserted from API contracts and build artefacts, not a recorded device run
  • limit Documentation screenshots are vector mockups of the shipped layouts
  • limit Minification is disabled for release builds, so APKs are larger than necessary
  • limit Some Player commands are not available to a MediaController; refusals are logged and automatic selection is kept
  • limit Before Android 10, exports are saved to the app's private external directory (the public Downloads path needs a runtime storage permission there)

Security

  • added Release keystore and keystore.properties are excluded from version control; releases are signed locally
  • added The app requests no INTERNET permission
