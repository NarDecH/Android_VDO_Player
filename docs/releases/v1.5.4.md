Local video player for Android: your own files, the phone's hardware decoders first with bundled FFmpeg decoders as the fallback, and phone-to-phone transfer over your own Wi-Fi. No account, no cloud.

## What's new

- **The screen reader now has the same run of the app as a sighted viewer** — 1.5.3 fixed what the player said; this release carries the same audit to the screens either side of it. The library no longer reads a file's title twice, the speed slider in Settings names itself and speaks the speed ("1.5x") rather than a bare number, a choice chip says which row it answers ("Columns, 3"), and the Settings cards are headings, so TalkBack can jump between them instead of reading one long list.
- **A phone in the transfer list is one tap target** — the whole row selects it, and the radio button is read with the device name. Tapping the name used to do nothing, and the dot alone was announced as an unnamed "radio button". The manual address field is named as well, because its placeholder disappears the moment something is typed.
- **Nothing changed for anyone not using a screen reader** — the same rows, the same chips and the same switch targets; the only visible difference is that the peer row now takes the full width of its card as a target.
- **Unchanged** — 1.5.4 upgrades over 1.5.3 in place, signed with the same key, and the bundled decoders, transfer protocol and stored settings are untouched.

149 JVM tests pass, and the emulator job runs 38 instrumented tests, including the three new Settings cases that read the semantics tree. Full changelog: https://github.com/NarDecH/Android_VDO_Player/blob/main/docs/CHANGELOG.md

## Before you install

Minimum Android 8.0 (API 26). `INTERNET` is declared only so the Transfer tab can open local sockets — nothing is uploaded, there is no account, and a log leaves the device only when you tap Share or Save.
