Local video player for Android: your own files, the phone's hardware decoders first with bundled FFmpeg decoders as the fallback, and phone-to-phone transfer over your own Wi-Fi. No account, no cloud.

## What's new

- **A silent file says so before you open it** — when nothing on this device can decode a file's audio, the player names the codec on a card before the file is prepared, with one tap to switch just the audio decoder to FFmpeg while the video keeps hardware decoding. When no decoder here could ever play that track the card says that instead, and offers **Next video** if the queue has one.
- **The library marks those files too** — a muted-speaker badge on the thumbnail in grid view, an icon beside the title in list view, and an **Audio** row in the details dialog, filled in by a bounded background sweep, so files you have never played are marked as well. Drawing the grid still opens nothing.
- **A rescued codec is remembered** — the next file with that codec switches to FFmpeg audio at prepare time, so the sound starts with the picture, including the episodes auto-advance reaches. The track is read with Media3's own extractors, the parser that plays the file, because the platform extractor does not list every track (handed the AC-3 clip it reported none). Settings → Playback lists the remembered codecs and can forget them.
- **Folder sections** — the toolbar's folder button (or Settings → Appearance) draws the library grouped by folder, in folder-name order, with a count per heading. A heading pins to the top while its own files scroll, taps through to that folder's filter, and its play button queues that folder alone.
- **Fixed** — announcements made in the player (decoder changes, repeat mode) were invisible, because the app's snackbar host was never composed behind the full-screen player; the player now carries its own host above the control bar.

77 more JVM tests, 149 in total, and the emulator job covers the silent-audio path against the packaged AC-3 clip. Full changelog: https://github.com/NarDecH/Android_VDO_Player/blob/main/docs/CHANGELOG.md

## Before you install

Minimum Android 8.0 (API 26). `INTERNET` is declared only so the Transfer tab can open local sockets — nothing is uploaded, there is no account, and a log leaves the device only when you tap Share or Save.
