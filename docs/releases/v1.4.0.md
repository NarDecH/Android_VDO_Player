Local video player for Android: your own files, the phone's hardware decoders first with bundled FFmpeg decoders as the fallback, and phone-to-phone transfer over your own Wi-Fi. No account, no cloud.

## What's new

- **The download is about half the size** — release builds are now minified with R8 and have their resources shrunk, so the APK for a modern phone is roughly half what it was in 1.3.0. The app itself is the same: same library, same player, same decoders.
- **Nothing was taken out of the app** — the old keep rules kept every class of this app and every Media3 class in full, which left the shrinker almost nothing to remove. The rules now name only what is actually reached by name at runtime: NextLib's JNI classes, the native method names, and the class names the log screen prints, so an exported log is still readable. Media3's own consumer rules cover the renderer constructors it loads reflectively.
- **The release build is built on every change** — CI compiles the minified release variant for every push and pull request, so a keep rule the shrinker rejects fails on the commit that changed it instead of on the tag that publishes the APKs.
- **Unchanged** — debug builds are not minified, so nothing about development or the emulator tests changes; 1.4.0 upgrades over 1.3.0 in place, signed with the same key.

149 JVM tests still pass, and the emulator job still plays the bundled clips through the platform and FFmpeg decoders. Full changelog: https://github.com/NarDecH/Android_VDO_Player/blob/main/docs/CHANGELOG.md

## Before you install

Minimum Android 8.0 (API 26). `INTERNET` is declared only so the Transfer tab can open local sockets — nothing is uploaded, there is no account, and a log leaves the device only when you tap Share or Save.
