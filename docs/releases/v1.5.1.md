Local video player for Android: your own files, the phone's hardware decoders first with bundled FFmpeg decoders as the fallback, and phone-to-phone transfer over your own Wi-Fi. No account, no cloud.

## What's new

- **The control bar position is in Settings too** — 1.5.0 put the switch in the player's title bar, which means opening a video to use it. Settings → Playback now has the same switch, so the bar can be moved to the top edge before you start. It writes the same stored choice, so the button in the player and the switch in Settings always agree.
- **Unchanged** — 1.5.1 upgrades over 1.5.0 in place, signed with the same key. Nothing else in the app changed: the player, the library, the decoders and the transfer tab are the builds 1.5.0 shipped.

Full changelog: https://github.com/NarDecH/Android_VDO_Player/blob/main/docs/CHANGELOG.md

## Before you install

Minimum Android 8.0 (API 26). `INTERNET` is declared only so the Transfer tab can open local sockets — nothing is uploaded, there is no account, and a log leaves the device only when you tap Share or Save.
